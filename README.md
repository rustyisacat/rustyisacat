I like taking hardware nobody wanted anymore (an Echo Show, a smartwatch, a TV remote, an old Dell laptop) and turning it into something I actually use every day. Most of my stuff lives over at **[rusty-workshop](https://github.com/rusty-workshop)**.

### ⌚ gadgets & wearables

| | |
|---|---|
| **[Gambit](https://gambit.rusty.is-a.dev)** | Lichess correspondence chess on a Wear OS watch |
| **[Flick](https://flick.rusty.is-a.dev)** | turn your watch into a programmable NFC tag |
| **[Muse Echo](https://muse-echo.rusty.is-a.dev)** | an Echo Show 5 reborn as a Muse gadget, with Puff the blob |
| **[Lookout](https://lookout.rusty.is-a.dev)** | clock, weather, homelab and chess wall display for the living room TV |
| **[TV Button Remap](https://tv-button-remap.rusty.is-a.dev)** | make a Sony BRAVIA remote's buttons do what you actually want |
| **[flipper-spotify-remote](https://github.com/rusty-workshop/flipper-spotify-remote)** | Spotify now-playing and remote for the Flipper Zero |

### 🖥️ linux desktop

| | |
|---|---|

| **[FocusGuard](https://focusguard.rusty.is-a.dev)** | app and website blocker for Arch + Hyprland, no root needed |
